# Snap Visuals & Media Website

A clean, responsive one-page website for Snap Visuals & Media.

## Files

- `index.html` — all website content/sections
- `style.css` — design, layout and responsive styling
- `script.js` — mobile menu interaction
- `assets/logo.png` — Snap Visuals & Media logo

## GitHub Pages

1. Create a new GitHub repository, e.g. `snap-visuals-media`.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the website.

Your site will normally be available at:
`https://YOUR-USERNAME.github.io/snap-visuals-media/`
